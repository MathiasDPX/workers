FontAwesome CDN

This is a Cloudflare Worker that gives you access to FontAwesome icons without paying nor importing their 5Gb libraries

You can see all icon packs, families and styles on Font Awesome Docs

Query parameters

Parameter Description
icon Required
family Family and style to use like jelly-regular
Default: solid
version See Changelog for versions
Default: v7.3.0

From a site-assets.fontawesome.com URL

https://site-assets.fontawesome.com/releases/v7.3.0/svgs-full/vellum-solid/donut.svg

In this example, the icon is donut with version v7.3.0 using vellum-solid. Which make this URL:

https://w.mathiasd.fr/fa/?icon=donut&family=vellum-solid&version=v7.3.0
